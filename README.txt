How to make the contact form work:
1. Go to https://formspree.io
2. Sign up or log in
3. Create a new form
4. Use hello@meriastudio.com as the receiving email
5. Formspree will give you an endpoint like: https://formspree.io/f/abcdwxyz
6. Open index.html
7. Find: https://formspree.io/f/YOUR_FORM_ID
8. Replace it with your real Formspree endpoint
9. Save the file and re-upload/redeploy your website
